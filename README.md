# 💼 Portfólio Pessoal

Este é o meu portfólio pessoal, desenvolvido para apresentar minha trajetória, habilidades e projetos na área de desenvolvimento web.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Google Fonts

## ✨ Funcionalidades

- Página inicial com apresentação.
- Seção "Sobre Mim".
- Galeria com meus principais projetos.
- Botão para visualizar todos os projetos.
- Layout responsivo.
- Navegação por menu.

## 🎯 Objetivo

Este projeto foi desenvolvido para praticar HTML e CSS e servir como meu portfólio profissional, onde reunirei os projetos desenvolvidos durante meus estudos.

## 📂 Projetos apresentados

- 🍰 Site de Receita
- 🔐 Tela de Login Responsiva
- 💼 Portfólio Pessoal
- Outros projetos desenvolvidos durante os estudos.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto pratiquei:

- Estruturação semântica com HTML.
- Estilização com CSS.
- Flexbox.
- Responsividade.
- Organização de código.
- Boas práticas de desenvolvimento.
